# G5 Unit 3 - Lesson 3 Quiz: Score Tracking

## Overview
This quiz tests students' understanding of how games keep track of points and manage game state.

## Quiz Content
- **Total Questions:** 8 multiple choice questions + 1 bonus question
- **Format:** Multiple choice (A, B, C, D)
- **Scoring:** 1 point per correct answer (8 points total)
- **Languages:** Bilingual (English/Chinese)

## Topics Covered
1. What are variables in programming
2. Common game variables (score, lives, timer, question)
3. Initialization - setting starting values
4. Updating scores for correct/incorrect answers
5. IF-THEN conditional statements
6. Different scoring systems

## Files
- `index.html` - Quiz interface
- `script.js` - Quiz logic and answer checking
- `styles.css` - Quiz styling with green theme
- `README.md` - This file

## How to Use
1. Open `index.html` in a web browser
2. Answer all 8 questions
3. Click "Check Answers" to see your score
4. Review feedback for each question
5. Use "Try Again" to reset and retake the quiz

## Bonus Question
Students create their own quiz question about score tracking, demonstrating understanding of variables and scoring.

## Technical Notes
- Uses vanilla JavaScript (no frameworks required)
- Responsive design for mobile and desktop
- Color-coded feedback (green for correct, red for incorrect)
- Star rating system based on score percentage
