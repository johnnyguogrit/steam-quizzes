# G5 Unit 3 - Lesson 1 Quiz: Quiz Design Principles

## Overview
This quiz tests students' understanding of quiz design principles learned in Lesson 1 of Grade 5 Unit 3.

## Quiz Content
- **Total Questions:** 8 multiple choice questions + 1 bonus question
- **Format:** Multiple choice (A, B, C, D)
- **Scoring:** 1 point per correct answer (8 points total)
- **Languages:** Bilingual (English/Chinese)

## Topics Covered
1. What makes a good quiz question
2. Types of quiz questions (multiple choice, true/false, fill-in-the-blank)
3. Answer choices and distractors
4. Steps to write quiz questions
5. Quiz design best practices

## Files
- `index.html` - Quiz interface
- `script.js` - Quiz logic and answer checking
- `styles.css` - Quiz styling with yellow/gold theme
- `README.md` - This file

## How to Use
1. Open `index.html` in a web browser
2. Answer all 8 questions
3. Click "Check Answers" to see your score
4. Review feedback for each question
5. Use "Try Again" to reset and retake the quiz

## Bonus Question
Students create their own quiz question about any topic, demonstrating understanding of good question design.

## Technical Notes
- Uses vanilla JavaScript (no frameworks required)
- Responsive design for mobile and desktop
- Color-coded feedback (green for correct, red for incorrect)
- Star rating system based on score percentage
