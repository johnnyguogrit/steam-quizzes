# G5 Unit 3 - Lesson 2 Quiz: User Input and Output

## Overview
This quiz tests students' understanding of how computers receive and respond to information through input and output.

## Quiz Content
- **Total Questions:** 8 multiple choice questions + 1 bonus question
- **Format:** Multiple choice (A, B, C, D)
- **Scoring:** 1 point per correct answer (8 points total)
- **Languages:** Bilingual (English/Chinese)

## Topics Covered
1. What is INPUT in computing
2. What is OUTPUT in computing
3. Examples of input devices (keyboard, mouse, touchscreen)
4. Examples of output (screen text, sounds, images)
5. Input-Output flow in quiz applications
6. Feedback systems in quizzes

## Files
- `index.html` - Quiz interface
- `script.js` - Quiz logic and answer checking
- `styles.css` - Quiz styling with blue theme
- `README.md` - This file

## How to Use
1. Open `index.html` in a web browser
2. Answer all 8 questions
3. Click "Check Answers" to see your score
4. Review feedback for each question
5. Use "Try Again" to reset and retake the quiz

## Answer Key
| Question | Correct Answer | Topic |
|----------|---------------|-------|
| Q1 | A | Definition of INPUT |
| Q2 | B | Examples of INPUT |
| Q3 | C | Definition of OUTPUT |
| Q4 | B | Answer choice as input |
| Q5 | B | Feedback as output |
| Q6 | B | Input-Check-Output flow |
| Q7 | D | Invalid input methods |
| Q8 | C | Color for correct answers |

## Bonus Question
Students create their own quiz question about input and output, demonstrating understanding of how computers communicate.

## Technical Notes
- Uses vanilla JavaScript (no frameworks required)
- Responsive design for mobile and desktop
- Color-coded feedback (green for correct, red for incorrect)
- Star rating system based on score percentage
