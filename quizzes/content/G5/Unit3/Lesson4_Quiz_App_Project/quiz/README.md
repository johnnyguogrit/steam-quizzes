# G5 Unit 3 - Lesson 4 Quiz: Quiz App Project

## Overview
This quiz tests students' understanding of the complete quiz app development project.

## Quiz Content
- **Total Questions:** 8 multiple choice questions + 1 bonus question
- **Format:** Multiple choice (A, B, C, D)
- **Scoring:** 1 point per correct answer (8 points total)
- **Languages:** Bilingual (English/Chinese)

## Topics Covered
1. Project planning and topic selection
2. Quiz requirements (10+ questions)
3. Question design best practices
4. Building and programming the quiz
5. Testing and debugging
6. Peer testing and feedback
7. Project presentation

## Files
- `index.html` - Quiz interface
- `script.js` - Quiz logic and answer checking
- `styles.css` - Quiz styling with purple theme
- `README.md` - This file

## How to Use
1. Open `index.html` in a web browser
2. Answer all 8 questions
3. Click "Check Answers" to see your score
4. Review feedback for each question
5. Use "Try Again" to reset and retake the quiz

| Question | Correct Answer | Topic |

## Bonus Question
Students create their own quiz question about building quiz apps, demonstrating understanding of the complete development process.

## Technical Notes
- Uses vanilla JavaScript (no frameworks required)
- Responsive design for mobile and desktop
- Color-coded feedback (green for correct, red for incorrect)
- Star rating system based on score percentage
