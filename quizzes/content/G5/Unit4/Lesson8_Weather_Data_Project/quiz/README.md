# Weather Data System Project Quiz - Interactive Evaluation

An interactive web-based quiz for G5 students to evaluate their understanding of Unit 4 Lesson 8: Weather Data System Project.

## Files

| File | Description |
|------|-------------|
| `index.html` | Main HTML structure for the quiz page |
| `styles.css` | Colorful, child-friendly styling |
| `script.js` | Interactive functionality and answer checking |

## Learning Objectives Evaluated

This quiz assesses understanding of:
- How to plan a weather data system
- How to collect and organize weather data
- How to analyze data using sorting and filtering
- How to create meaningful visualizations
- How to present findings to the class

## How to Use

### Method 1: Direct Open
Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Method 2: Local Server (Recommended)
```bash
# Using Python
python -m http.server 8000

# Then open: http://localhost:8000
```

## Features

- **8 Multiple Choice Questions**: Covers all key lesson concepts
- **Bilingual Support**: English and Chinese for all questions
- **Visual Feedback**: Color-coded correct/incorrect answers
- **Score System**: Star ratings based on performance (out of 8)
- **Retry Option**: Students can try again after reviewing
- **Mobile Friendly**: Responsive design for tablets
- **Accessibility**: Large buttons and clear fonts for young learners
