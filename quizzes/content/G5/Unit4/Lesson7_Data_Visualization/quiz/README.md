# Data Analysis and Visualization Quiz - Interactive Evaluation

An interactive web-based quiz for G5 students to evaluate their understanding of Unit 4 Lesson 7: Data Analysis and Visualization.

## Files

| File | Description |
|------|-------------|
| `index.html` | Main HTML structure for the quiz page |
| `styles.css` | Colorful, child-friendly styling |
| `script.js` | Interactive functionality and answer checking |

## Learning Objectives Evaluated

This quiz assesses understanding of:
- What is data visualization
- Different types of charts and graphs
- How to choose the right chart for your data
- How to create charts from weather data
- How to read and interpret charts

## How to Use

### Method 1: Direct Open
Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Method 2: Local Server (Recommended)
```bash
# Using Python
python -m http.server 8000

# Then open: http://localhost:8000
```

## Features

- **8 Multiple Choice Questions**: Covers all key lesson concepts
- **Bilingual Support**: English and Chinese for all questions
- **Visual Feedback**: Color-coded correct/incorrect answers
- **Score System**: Star ratings based on performance (out of 8)
- **Retry Option**: Students can try again after reviewing
- **Mobile Friendly**: Responsive design for tablets
- **Accessibility**: Large buttons and clear fonts for young learners

| Question | Correct Answer |
|----------|---------------|
| Q1: What is data visualization? | A) Making pictures to help us understand data |
| Q2: Best chart for comparing categories | C) Bar chart |
| Q3: Chart showing changes over time | C) Line chart |
| Q4: What does a pie chart show? | B) Parts of a whole (percentages) |
| Q5: First step to create a chart | A) Select your data |
| Q6: Why charts need titles and labels | C) So people can understand what the chart shows |
| Q7: Chart for rainfall by city | B) Bar chart |
| Q8: Chart for temperature this week | A) Line chart |
