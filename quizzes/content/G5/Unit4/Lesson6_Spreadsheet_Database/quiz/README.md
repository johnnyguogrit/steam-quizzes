# Spreadsheet Database Functions Quiz - Interactive Evaluation

An interactive web-based quiz for G5 students to evaluate their understanding of Unit 4 Lesson 6: Spreadsheet Database Functions.

## Files

| File | Description |
|------|-------------|
| `index.html` | Main HTML structure for the quiz page |
| `styles.css` | Colorful, child-friendly styling |
| `script.js` | Interactive functionality and answer checking |

## Learning Objectives Evaluated

This quiz assesses understanding of:
- How spreadsheets organize data in rows and columns
- How to SORT data in different ways
- How to FILTER to find specific information
- How to use basic formulas with weather data

## How to Use

### Method 1: Direct Open
Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Method 2: Local Server (Recommended)
```bash
# Using Python
python -m http.server 8000

# Then open: http://localhost:8000
```

## Features

- **8 Multiple Choice Questions**: Covers all key lesson concepts
- **Bilingual Support**: English and Chinese for all questions
- **Visual Feedback**: Color-coded correct/incorrect answers
- **Score System**: Star ratings based on performance (out of 8)
- **Retry Option**: Students can try again after reviewing
- **Mobile Friendly**: Responsive design for tablets
- **Accessibility**: Large buttons and clear fonts for young learners

## Answer Key

| Question | Correct Answer |
|----------|---------------|
| Q1: What is each box called? | B) A cell |
| Q2: Columns are labeled with | B) Letters (A, B, C...) |
| Q3: What does SORT do? | C) Arranges data in a specific order |
| Q4: What does FILTER do? | A) Shows only the data you want to see |
| Q5: Formula for AVERAGE | C) =AVERAGE(B2:B10) |
| Q6: Formula for MAXIMUM | A) =MAX(B2:B10) |
| Q7: What does colon mean in B2:B10? | B) Through or to (from B2 to B10) |
| Q8: First row is called | C) The header row (contains field names) |
