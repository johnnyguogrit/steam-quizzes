# Lesson 7 Quiz - Network Hardware
# 第七课测验 - 网络硬件

## Overview | 概述

This quiz tests students' understanding of network hardware devices including:
本测验测试学生对以下网络硬件设备的理解：

- Router (路由器) - Traffic director of networks
- Switch (交换机) - Connects multiple devices
- Server (服务器) - Provides services
- Network cables (Ethernet, fiber optic)
- WiFi and wireless networks
- Network topology

## Quiz Structure | 测验结构

- **7 Multiple Choice Questions** | 7道选择题
- **1 Bonus Question** (Identify network devices) | 1道附加题（识别网络设备）
- **Bilingual** (English/Chinese) | 双语（英文/中文）

## Questions | 问题

1. **Router definition** | 路由器定义
   - Correct: A - A device that connects networks and directs data

2. **Router vs Switch** | 路由器与交换机
   - Correct: B - Router connects networks; switch connects devices within a network

3. **Server definition** | 服务器定义
   - Correct: B - A powerful computer that provides services to other computers

4. **Common network cable** | 常见网络电缆
   - Correct: C - Ethernet cable

5. **WiFi technology** | WiFi技术
   - Correct: C - Radio waves

6. **Network topology** | 网络拓扑
   - Correct: B - The shape or layout of a network

7. **Most common topology** | 最常见拓扑
   - Correct: A - Star topology

## Bonus Question | 附加题

Students name two network devices they have seen and explain what each does.
学生说出他们见过的两种网络设备并解释各自的作用。

## How to Use | 使用方法

1. Open `index.html` in a web browser
2. Answer all 7 multiple choice questions
3. Complete the bonus question
4. Click "Submit Quiz" to see results
