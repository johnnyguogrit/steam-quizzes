# Lesson 6 Quiz - IP Addresses and Protocols
# 第六课测验 - IP地址和协议

## Overview | 概述

This quiz tests students' understanding of IP addresses and network protocols including:
本测验测试学生对以下IP地址和网络协议概念的理解：

- What IP stands for (Internet Protocol)
- IP address format (four groups of numbers)
- IP address as device address
- Protocol definition
- Common protocols (HTTP, HTTPS, SMTP, TCP)
- Why unique IP addresses matter

## Quiz Structure | 测验结构

- **7 Multiple Choice Questions** | 7道选择题
- **1 Bonus Question** (Find your IP address) | 1道附加题（查找你的IP地址）
- **Bilingual** (English/Chinese) | 双语（英文/中文）

## Questions | 问题

1. **IP meaning** | IP的含义
   - Correct: B - Internet Protocol

2. **IP address comparison** | IP地址比喻
   - Correct: B - A home address for your device

3. **Valid IP address format** | 有效IP地址格式
   - Correct: A - 192.168.1.100

4. **Number groups in IP** | IP中的数字组数
   - Correct: C - 4 groups

5. **Protocol definition** | 协议定义
   - Correct: B - Rules for communication

6. **HTTPS meaning** | HTTPS含义
   - Correct: A - HyperText Transfer Protocol Secure

7. **Unique IP addresses** | 唯一IP地址
   - Correct: B - Data wouldn't know which device to go to

## Bonus Question | 附加题

Students find and write down the IP address of the device they are using.
学生查找并写下他们正在使用的设备的IP地址。

## How to Use | 使用方法

1. Open `index.html` in a web browser
2. Answer all 7 multiple choice questions
3. Complete the bonus question by finding your device's IP address
4. Click "Submit Quiz" to see results
