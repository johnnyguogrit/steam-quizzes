# Lesson 8 Quiz - Network Design Project
# 第八课测验 - 网络设计项目

## Overview | 概述

This quiz tests students' understanding of the network design process and Unit 4 concepts including:
本测验测试学生对网络设计流程和第四单元概念的理解：

- Network design steps (analyze, design, select hardware, diagram, justify)
- Network zones and security
- Network diagrams
- Hardware selection
- Scalability
- Unit 4 review (networks, IP addresses, hardware)

## Quiz Structure | 测验结构

- **7 Multiple Choice Questions** | 7道选择题
- **1 Bonus Question** (Design a small network) | 1道附加题（设计小型网络）
- **Bilingual** (English/Chinese) | 双语（英文/中文）

## Questions | 问题

1. **First design step** | 设计第一步
   - Correct: B - Analyze requirements

2. **Separate networks** | 分离网络
   - Correct: B - For security

3. **Network zone** | 网络区域
   - Correct: C - A separate part of a network for specific users

4. **Router placement** | 路由器位置
   - Correct: B - Near the internet connection

5. **Network diagram purpose** | 网络图目的
   - Correct: B - To show how devices are connected

6. **Scalability** | 可扩展性
   - Correct: C - The ability to expand the network in the future

7. **Diagram contents** | 图表内容
   - Correct: A - All major components and connections

## Bonus Question | 附加题

Students design a simple network for a small office with 5 computers, 1 printer, and internet access. They list the hardware needed (router, switch, cables, etc.).
学生为有5台电脑、1台打印机和互联网接入的小型办公室设计网络，并列出所需硬件。

## How to Use | 使用方法

1. Open `index.html` in a web browser
2. Answer all 7 multiple choice questions
3. Complete the bonus question with a network design
4. Click "Submit Quiz" to see results
