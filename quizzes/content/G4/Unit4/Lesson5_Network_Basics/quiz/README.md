# Lesson 5 Quiz - Network Basics
# 第五课测验 - 网络基础

## Overview | 概述

This quiz tests students' understanding of basic network concepts including:
本测验测试学生对以下基本网络概念的理解：

- What is a computer network (什么是计算机网络)
- Types of networks (PAN, LAN, WAN)
- Network devices (router, server, client)
- Network connections (wired, wireless, mobile)
- How data travels (packets)

## Quiz Structure | 测验结构

- **7 Multiple Choice Questions** | 7道选择题
- **1 Bonus Question** (Drawing/Diagram) | 1道附加题（绘图）
- **Bilingual** (English/Chinese) | 双语（英文/中文）

## Questions | 问题

1. **Definition of a computer network** | 计算机网络定义
   - Correct: A - Two or more computers connected together to share resources and information

2. **LAN meaning** | LAN的含义
   - Correct: B - Local Area Network

3. **Largest network type** | 最大网络类型
   - Correct: C - WAN (Wide Area Network)

4. **Router function** | 路由器功能
   - Correct: B - The traffic director of a network

5. **Data pieces** | 数据片段
   - Correct: B - Packets

6. **Fastest connection** | 最快连接
   - Correct: C - Wired (Ethernet cable)

7. **Server definition** | 服务器定义
   - Correct: B - A powerful computer that stores and provides information

## Bonus Question | 附加题

Draw a simple diagram of student's home network with at least 3 devices labeled.
画出学生家庭网络的简单示意图，至少标出3个设备。

## How to Use | 使用方法

1. Open `index.html` in a web browser
2. Answer all 7 multiple choice questions
3. Complete the bonus question
4. Click "Submit Quiz" to see results
