# Lesson 5 Quiz - Intro to Spreadsheets
第五课测验 - 电子表格入门

## Overview

This quiz tests students' understanding of basic spreadsheet concepts including rows, columns, and cells.
本测验测试学生对电子表格基本概念的理解，包括行、列和单元格。

## Questions

1. **Rows vs Columns** - Identifying that rows are horizontal (numbered)
   **行 vs 列** - 识别行是横向的（用数字表示）

2. **Column Representation** - Understanding that columns use letters (A, B, C...)
   **列的表示** - 理解列使用字母（A、B、C...）

3. **Cell Definition** - Knowing that cells are the individual boxes for data
   **单元格定义** - 知道单元格是存放数据的单个格子

4. **Cell Addresses** - Reading cell addresses correctly (e.g., A3 = Column A, Row 3)
   **单元格地址** - 正确读取单元格地址（例如：A3 = 列A，行3）

## How to Use

1. Open `index.html` in a web browser
   在浏览器中打开 `index.html`

2. Select an answer for each question
   为每个问题选择一个答案

   立即获得答案反馈

   在底部查看你的得分（满分4分）

   点击"再试一次"重新开始测验

## Files

- `index.html` - Main quiz page structure / 主测验页面结构
- `script.js` - Quiz logic and answers / 测验逻辑和答案

## Learning Objectives

By the end of this lesson, students will be able to:
完成本课后，学生将能够：

- Identify rows and columns in a spreadsheet
  识别电子表格中的行和列

- Understand how cells are named (letter + number)
  理解单元格如何命名（字母+数字）

- Navigate to specific cell addresses
  导航到特定的单元格地址

- Understand the basic structure of a spreadsheet
  理解电子表格的基本结构

绿色/表格主题 - 代表电子表格的网格特性
