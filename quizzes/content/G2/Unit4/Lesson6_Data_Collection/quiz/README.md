# Lesson 6 Quiz - Data Collection
第六课测验 - 数据收集

## Overview

This quiz tests students' understanding of tally marks and basic data collection methods.
本测验测试学生对计数符号和基本数据收集方法的理解。

## Questions

1. **Reading Tally Marks** - Understanding that |||| = 4 marks
   **读取计数符号** - 理解|||| = 4个计数符号

2. **Writing Five with Tally Marks** - Knowing that |||| = 5 (diagonal crosses out four)
   **用计数符号写五** - 知道|||| = 5（斜线穿过四个）

3. **What is a Survey** - Understanding that surveys ask questions to collect information
   **什么是调查** - 理解调查是通过问问题来收集信息

4. **Purpose of Tally Marks** - Knowing tally marks are for quick counting and recording
   **计数符号的用途** - 知道计数符号用于快速计数和记录

## How to Use

1. Open `index.html` in a web browser
   在浏览器中打开 `index.html`

2. Select an answer for each question
   为每个问题选择一个答案

3. Get immediate feedback on your answer
   立即获得答案反馈

4. See your score at the bottom (out of 4)
   在底部查看你的得分（满分4分）

5. Click "Try Again" to reset the quiz
   点击"再试一次"重新开始测验

## Files

## Learning Objectives

By the end of this lesson, students will be able to:
完成本课后，学生将能够：

- Read and write tally marks correctly
  正确读写计数符号

- Understand that |||| = 4 and |||| = 5
  理解|||| = 4，|||| = 5

- Conduct simple surveys
  进行简单的调查

- Record data using tally marks
  使用计数符号记录数据
