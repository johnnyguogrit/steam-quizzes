# Lesson 8 Quiz - Data Cafe Project
第八课测验 - 数据咖啡馆项目

## Overview

This quiz tests students' understanding of the Data Cafe Project, including menu design and presentation skills.
本测验测试学生对数据咖啡馆项目的理解，包括菜单设计和展示技能。

## Questions

1. **Project Purpose** - Understanding that the project involves designing a menu and collecting data
   **项目目的** - 理解项目涉及设计菜单和收集数据

2. **Menu Contents** - Knowing what goes on a cafe menu (food, drinks, prices)
   **菜单内容** - 知道咖啡馆菜单上有什么（食物、饮料、价格）

3. **Presentation** - Understanding that students present their work to the class
   **展示** - 理解学生要向全班展示他们的作品

4. **Tools Used** - Knowing that spreadsheets are used to organize cafe data
   **使用的工具** - 知道用电子表格来组织咖啡馆数据

## How to Use

1. Open `index.html` in a web browser
   在浏览器中打开 `index.html`

2. Select an answer for each question
   为每个问题选择一个答案

3. Get immediate feedback on your answer
   立即获得答案反馈

4. See your score at the bottom (out of 4)
   在底部查看你的得分（满分4分）

5. Click "Try Again" to reset the quiz
   点击"再试一次"重新开始测验

## Files

- `index.html` - Main quiz page structure / 主测验页面结构
- `script.js` - Quiz logic and answers / 测验逻辑和答案
- `styles.css` - Brown cafe theme styling / 棕色咖啡馆主题样式

## Learning Objectives

By the end of this lesson, students will be able to:
完成本课后，学生将能够：

- Design a simple cafe menu with prices
   设计带有价格的简单咖啡馆菜单

- Collect survey data about favorite foods
   收集关于最喜欢食物的调查数据

- Organize data in a spreadsheet
   在电子表格中组织数据

- Present findings to the class
   向全班展示发现

## Project Steps

The Data Cafe Project involves:
数据咖啡馆项目包括：

1. **Menu Design** - Create a cafe menu with items and prices
   **菜单设计** - 创建带有项目和价格的咖啡馆菜单

2. **Data Collection** - Survey classmates about their favorite menu items
   **数据收集** - 调查同学最喜欢的菜单项目

3. **Data Organization** - Use spreadsheets to organize the data
   **数据组织** - 使用电子表格组织数据

4. **Presentation** - Share results with the class
   **展示** - 与全班分享结果

## Color Theme

Brown/Cafe Theme - Represents coffee, cafe atmosphere, and warmth
棕色/咖啡馆主题 - 代表咖啡、咖啡馆氛围和温暖
