# Lesson 7 Quiz - Data Analysis
第七课测验 - 数据分析

## Overview

This quiz tests students' understanding of reading bar charts and comparing data.
本测验测试学生对读取柱状图和比较数据的理解。

## Questions

1. **Bar Chart Purpose** - Understanding that bar charts show data with different length bars
   **柱状图的用途** - 理解柱状图用不同长度的柱子展示数据

2. **Identifying "Most"** - Knowing that the most = tallest bar
   **识别"最多"** - 知道最多 = 最高的柱子

3. **Comparing Numbers** - Understanding 5 > 3 (apples has more than bananas)
   **比较数字** - 理解5 > 3（苹果比香蕉多）

4. **Understanding "Least"** - Knowing that least = smallest number
   **理解"最少"** - 知道最少 = 最小的数字

1. Open `index.html` in a web browser
   在浏览器中打开 `index.html`

2. Select an answer for each question
   为每个问题选择一个答案

   立即获得答案反馈

   在底部查看你的得分（满分4分）

   点击"再试一次"重新开始测验

## Files

## Learning Objectives

By the end of this lesson, students will be able to:
完成本课后，学生将能够：

- Read a bar chart correctly
  正确读取柱状图

- Identify which category has the most (tallest bar)
  识别哪个类别最多（最高的柱子）

- Identify which category has the least (shortest bar)
  识别哪个类别最少（最短的柱子）

- Compare quantities using > and <
  使用大于和小于符号比较数量
