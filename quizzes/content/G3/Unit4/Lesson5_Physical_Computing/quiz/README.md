# Lesson 5 Quiz - Introduction to Physical Computing
## G3 Unit 4 - Let's Get Physical! - 第五课测验

### Overview / 概述

This quiz tests students' understanding of physical computing basics and the micro:bit device.
本测验测试学生对物理计算基础和micro:bit设备的理解。

### Topics Covered / 涵盖主题

1. **What is Physical Computing?** - Building interactive systems that sense and respond
   **什么是物理计算?** - 构建可以感知和响应的交互系统

2. **micro:bit Features** - 25 LED lights, buttons, sensors
   **micro:bit特性** - 25个LED灯、按钮、传感器

3. **Inputs and Outputs** - Understanding how computers interact with the world
   **输入和输出** - 理解计算机如何与世界交互

4. **MakeCode Editor** - Programming environment for micro:bit
   **MakeCode编辑器** - micro:bit的编程环境

### Questions / 问题

| # | Question (English) | Question (Chinese) | Correct Answer |
|---|-------------------|-------------------|----------------|
| 1 | What is physical computing? | 什么是物理计算? | B - Building interactive systems... |
| 2 | How many red LED lights are on the micro:bit? | micro:bit上有多少个红色LED灯? | C - 25 lights (5x5 grid) |
| 3 | Which of these is an INPUT on the micro:bit? | 以下哪项是micro:bit上的输入? | A - Pressing button A or B |
| 4 | What website do we use to program the micro:bit? | 我们使用什么网站来编程micro:bit? | B - makecode.microbit.org |

### Bonus Challenge / 奖励挑战

**Question:** Name the sensor that detects movement and shaking on the micro:bit!
**问题:** 说出micro:bit上检测移动和摇晃的传感器名称!

**Answer:** Accelerometer (加速度传感器)

### How to Use / 使用方法

1. Open `index.html` in a web browser
   在网络浏览器中打开 `index.html`

2. Read each question in both English and Chinese
   阅读每个问题的英文和中文版本

3. Select your answer for each question
   为每个问题选择你的答案

4. Click "Submit" to check your answers
   点击"提交"检查你的答案

5. Try the bonus challenge for extra points!
   尝试奖励挑战获得额外分数!

### Learning Objectives / 学习目标

After completing this quiz, students should be able to:
完成本测验后,学生应该能够:

- Define physical computing in their own words
   用自己的话定义物理计算

- Identify key features of the micro:bit device
   识别micro:bit设备的关键特性

- Distinguish between inputs and outputs
   区分输入和输出

- Navigate to the MakeCode programming website
   导航到MakeCode编程网站

### Extension Activities / 扩展活动

1. **Explore Real Examples** - Find physical computing devices at home (smart lights, game controllers)
   **探索真实例子** - 在家里找到物理计算设备(智能灯、游戏控制器)

2. **micro:bit Discovery** - Use the MakeCode simulator to explore different blocks
   **micro:bit探索** - 使用MakeCode模拟器探索不同的模块

3. **Input/Output Hunt** - Make a list of inputs and outputs in everyday technology
   **输入/输出搜寻** - 列出日常技术中的输入和输出
