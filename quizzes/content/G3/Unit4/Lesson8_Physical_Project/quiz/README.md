# Lesson 8 Quiz - Physical Computing Final Project
## G3 Unit 4 - Let's Get Physical! - 第八课测验

### Overview / 概述

This quiz tests students' understanding of the project creation process, design thinking, and presentation skills.
本测验测试学生对项目创建过程、设计思维和展示技能的理解。

### Topics Covered / 涵盖主题

1. **Project Planning** - Steps to create a project
   **项目规划** - 创建项目的步骤

2. **Project Options** - Game, Helper, Creative categories
   **项目选项** - 游戏、帮手、创意类别

3. **Design Thinking** - User-focused design
   **设计思维** - 以用户为中心的设计

4. **Peer Testing** - Testing and feedback
   **同伴测试** - 测试和反馈

### Questions / 问题

### Bonus Challenge / 奖励挑战

**Question:** What is the name of the event where you show your project to the class?
**问题:** 你向班级展示项目的活动叫什么?

**Answer:** Showcase / Expo / Exhibition (展示/博览会)

### How to Use / 使用方法

1. Open `index.html` in a web browser
2. Read each question in both English and Chinese
3. Select your answer for each question
4. Click "Submit" to check your answers
5. Try the bonus challenge for extra points!
