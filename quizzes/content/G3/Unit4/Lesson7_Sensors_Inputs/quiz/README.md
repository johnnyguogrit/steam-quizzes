# Lesson 7 Quiz - Sensors and Inputs
## G3 Unit 4 - Let's Get Physical! - 第七课测验

### Overview / 概述

This quiz tests students' understanding of all micro:bit sensors and how they work as inputs.
本测验测试学生对所有micro:bit传感器以及它们如何作为输入工作的理解。

### Topics Covered / 涵盖主题

1. **All micro:bit Sensors** - Buttons, accelerometer, light, temperature, touch logo
   **所有micro:bit传感器** - 按钮、加速度、光线、温度、触摸标志

2. **Light Sensor** - Hidden in LED matrix
   **光线传感器** - 隐藏在LED矩阵中

3. **Touch Logo** - The gold logo button
   **触摸标志** - 金色标志按钮

4. **Temperature Sensor** - Measuring heat/cold
   **温度传感器** - 测量冷热

### Questions / 问题

| # | Question (English) | Question (Chinese) | Correct Answer |
|---|-------------------|-------------------|----------------|
| 1 | How many sensors does the micro:bit have? | micro:bit有多少个传感器? | C - 5 sensors |

### Bonus Challenge / 奖励挑战

**Question:** What number does the light sensor return when it is VERY dark?
**问题:** 光线传感器在非常暗时返回什么数字?

**Answer:** 0 (on a scale of 0-255)
