# Lesson 6 Quiz - micro:bit Projects (Step Counter)
## G3 Unit 4 - Let's Get Physical! - 第六课测验

### Overview / 概述

This quiz tests students' understanding of variables, the accelerometer sensor, and building a step counter project.
本测验测试学生对变量、加速度传感器和构建计步器项目的理解。

### Topics Covered / 涵盖主题

1. **Accelerometer Sensor** - Motion detection in micro:bit
   **加速度传感器** - micro:bit中的运动检测

2. **Variables** - Storage boxes for changing data
   **变量** - 存储变化数据的盒子

3. **Step Counter Logic** - How counting steps works
   **计步器逻辑** - 计数步数如何工作

4. **Programming Blocks** - Set, change, and show commands
   **编程模块** - 设为、增加和显示命令

### Questions / 问题

| # | Question (English) | Question (Chinese) | Correct Answer |
|---|-------------------|-------------------|----------------|
| 1 | What is an accelerometer? | 什么是加速度传感器? | B - Detects movement/shaking |
| 2 | What is a VARIABLE in programming? | 什么是编程中的变量? | A - Box for changing info |
| 3 | What happens when you shake the micro:bit in step counter? | 摇晃时会发生什么? | C - Steps go up by 1 |
| 4 | What does "set steps to 0" do? | "将steps设为0"是做什么? | B - Resets to zero |

### Bonus Challenge / 奖励挑战

**Question:** In programming, what do we call "IF something happens, THEN do this"?
**问题:** 在编程中，"如果某事发生，那么做这个"叫什么?

**Answer:** Conditional (条件) or If-Then logic

### How to Use / 使用方法

1. Open `index.html` in a web browser
2. Read each question in both English and Chinese
3. Select your answer for each question
4. Click "Submit" to check your answers
5. Try the bonus challenge for extra points!
