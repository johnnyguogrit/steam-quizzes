# Lesson 4 Quiz - Geometric Art Project
# 第四课测验 - 几何艺术项目

## Overview / 概述

This quiz tests students' understanding of the Geometric Art project requirements and presentation.
本测验测试学生对几何艺术项目要求和展示的理解。

## Quiz Content / 测验内容

### Question 1 / 问题 1
**What is one requirement for the Geometric Art project? / 几何艺术项目的一个要求是什么？**
- Correct Answer: Use at least one loop / 至少使用一个循环 (A)

### Question 2 / 问题 2
**What Scratch extension do you use to add colors to your drawing? / 你使用哪个Scratch扩展来给绘画添加颜色？**
- Correct Answer: Pen extension / 画笔扩展 (B)

### Question 3 / 问题 3
**What is the purpose of planning before coding your art? / 在编写艺术代码之前计划的目的是什么？**
- Correct Answer: To know what blocks to use / 知道使用什么积木 (B)

### Question 4 / 问题 4
**What happens during a gallery walk? / 在画廊展示期间会发生什么？**
- Correct Answer: Students share and view each other's artwork / 学生分享和观看彼此的作品 (B)

## Learning Objectives / 学习目标

- Understand project requirements
- 理解项目要求
- Know how to use the Pen extension for colors
- 知道如何使用画笔扩展添加颜色
- Learn the importance of planning before coding
- 学习在编码之前计划的重要性
- Understand gallery walk presentation format
- 理解画廊展示的格式

## How to Use / 使用方法

1. Open `index.html` in a web browser
   在网页浏览器中打开 index.html

2. Answer all 4 multiple choice questions
   回答所有4道选择题

3. Click "Submit / 提交" to see your score
   点击"提交"查看分数

4. Review feedback and try again if needed
   查看反馈，需要时再试一次
