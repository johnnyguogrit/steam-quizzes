# Lesson 3 Quiz - Nested Loops
# 第三课测验 - 嵌套循环

## Overview / 概述

This quiz tests students' understanding of nested loops in programming.
本测验测试学生对编程中嵌套循环的理解。

## Quiz Content / 测验内容

### Question 1 / 问题 1
**What is a nested loop? / 什么是嵌套循环？**
- Correct Answer: A loop inside another loop / 一个循环在另一个循环里面 (B)

### Question 2 / 问题 2
**In a nested loop, which loop runs first? / 在嵌套循环中，哪个循环先运行？**
- Correct Answer: The inner loop / 内层循环 (B)

### Question 3 / 问题 3
**If the outer loop repeats 5 times and the inner loop repeats 3 times, how many total actions? / 如果外层循环重复5次，内层循环重复3次，总共执行多少次动作？**
- Correct Answer: 15 times / 15次 (C)

### Question 4 / 问题 4
**What pattern does a nested loop create in the star example? / 在星形图案例子中，嵌套循环创建了什么图案？**
- Correct Answer: A pattern of triangles repeated / 重复的三角形图案 (B)

## Learning Objectives / 学习目标

- Understand what a nested loop is
- 理解什么是嵌套循环
- Know which loop runs first in nesting
- 知道嵌套中哪个循环先运行
- Calculate total repetitions in nested loops
- 计算嵌套循环的总重复次数
- Visualize patterns created by nested loops
- 可视化嵌套循环创建的图案
