# Lesson 1 Quiz - Understanding Loops
# 第一课测验 - 理解循环

## Overview / 概述

This quiz tests students' understanding of basic loop concepts in programming.
本测验测试学生对编程中基本循环概念的理解。

## Quiz Content / 测验内容

### Question 1 / 问题 1
**What is a loop in programming? / 什么是程序中的循环？**
- Correct Answer: A command that repeats actions / 重复执行命令的代码 (B)

### Question 2 / 问题 2
**Which of these is NOT an example of a loop in daily life? / 以下哪个不是日常生活中的循环例子？**
- Correct Answer: Reading a book once only / 只读一次书 (D)

### Question 3 / 问题 3
**Why are loops useful in programming? / 为什么循环在编程中很有用？**
- Correct Answer: They help us write less code / 帮助我们写更少的代码 (B)

### Question 4 / 问题 4
**What does "REPEAT 4 times" mean? / "REPEAT 4 times" 是什么意思？**
- Correct Answer: Do something 4 times / 做某事4次 (A)

## Learning Objectives / 学习目标

- Understand what a loop is in programming
- 理解编程中循环的概念
- Identify loops in daily life
- 识别日常生活中的循环
- Understand why loops are useful
- 理解为什么循环很有用
- Learn basic repeat pseudocode
- 学习基本的重复伪代码
