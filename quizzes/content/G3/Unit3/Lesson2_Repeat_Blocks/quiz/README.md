# Lesson 2 Quiz - Repeat Blocks in Scratch
# 第二课测验 - Scratch重复积木

## Overview / 概述

This quiz tests students' understanding of Scratch interface and repeat blocks.
本测验测试学生对Scratch界面和重复积木的理解。

## Quiz Content / 测验内容

### Question 1 / 问题 1
**Where are the REPEAT blocks located in Scratch? / Scratch中的重复积木在哪个类别中？**
- Correct Answer: Control category (orange) / 控制类别（橙色）(B)

### Question 2 / 问题 2
**What color are the MOTION blocks in Scratch? / Scratch中的运动积木是什么颜色的？**
- Correct Answer: Blue / 蓝色 (A)

### Question 3 / 问题 3
**To draw a square, how many times should you repeat and how many degrees to turn? / 画正方形需要重复几次，每次转多少度？**
- Correct Answer: Repeat 4, turn 90 / 重复4次，转90度 (B)

### Question 4 / 问题 4
**How do you calculate the turn angle for a shape? / 如何计算形状的旋转角度？**
- Correct Answer: 360 ÷ sides / 360 ÷ 边数 (C)

## Learning Objectives / 学习目标

- Identify Scratch block categories by color
- 通过颜色识别Scratch积木类别
- Understand where control blocks are located
- 理解控制积木的位置
- Learn to draw basic shapes using loops
- 学习使用循环绘制基本形状
- Apply the 360 ÷ sides formula
- 应用360÷边数的公式

## How to Use / 使用方法

1. Open `index.html` in a web browser
   在网页浏览器中打开 index.html

   回答所有4道选择题
